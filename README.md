# AngularFrontendProject – Multi-Backend Integrated (Fakestore • Flask • Spring Boot • .NET)

This Angular project acts as a **single unified frontend** that communicates with **four different backend systems**, making it a complete multi-API integration project.

Connected Backends:

- **Fakestore API**
- **Flask REST API**
- **Spring Boot REST API**
- **.NET REST API**

All integrations are fully tested with CRUD operations (where supported), auto-refresh, forms, UI components, and routing.
